CCM Feedback — MVP Demo Page

Use the floating action button (bottom-right) to drop a comment anywhere on this page. Pins persist in localStorage.

Intro

What is this?

A single-script-tag feedback widget. No backend, no accounts, no multiplayer — just you, the page you're reviewing, and a JSON file you can hand off to a developer.

  • Click the FAB → radial menu
  • Pin (crosshair) → click any element to comment
  • Toggle (eye) → show/hide pins
  • Export (arrow) → download JSON of all annotations
Sample content

Try commenting on anything here

Hover over an element while in pin mode — it gets a blue outline. Click to drop a pin. A popover opens with a textarea. Cmd/Ctrl + Enter submits.

Feedback pins survive page reloads. Use the export button to hand off work to engineering.
