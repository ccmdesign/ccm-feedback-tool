CCM Feedback

One script tag. Pin comments on any element. Export as JSON.

Install

<script src="https://ccm-feedback-582.netlify.app/w.js"
        data-project="my-project" defer></script>

That's it. The FAB appears bottom-right on desktop (hidden below 768 px).

What it does

  • Click the FAB → radial menu (pin / toggle / export).
  • Pin mode = crosshair. Click any element to leave a comment.
  • Pins persist in localStorage and re-render on reload.
  • Export downloads a JSON file with every annotation + its DOM anchor.

Options

data-project   (required)    localStorage namespace
data-accent    (#0066ff)     hex color
data-theme     (light)       light | dark | auto
data-debug     (off)         "true" to console-log lifecycle
