02 — installation

Give this to your agent.

Paste the prompt into Claude Code, Cursor, or whichever agent runs your repo. The widget auto-namespaces by hostname — no project slug, no config, just one script tag.

Need cloud sync or production hardening? More agent prompts ↗

Add the CCM Feedback widget to my site so we can collect visual feedback on every page. 1. Drop this single script tag right before </body> in the global layout (e.g. _app.tsx, app.html, layout.astro, or whichever file renders the page chrome for every route): <script src="https://ccm-feedback-582.netlify.app/w.js" defer></script> 2. That's it. The widget auto-namespaces feedback by hostname, so production and staging stay isolated automatically. 3. Optional: pass data-accent="#hex" to match brand color and data-theme="auto" if the site has a dark mode. The widget is desktop-only and shows a floating button bottom-right. Confirm once installed and tell me which file you edited.
